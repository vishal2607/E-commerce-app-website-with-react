# E-Commerce Shop

A responsive e-commerce website built with React and JavaScript.

## Features

* Product browsing with pagination
* Product search
* Category filtering
* Price sorting
* Product details pages
* Shopping cart with quantity management
* Wishlist functionality
* Cart and wishlist persistence using localStorage
* Responsive and interactive UI

## Tech Stack

* React
* JavaScript
* React Router
* CSS
* Vite
* DummyJSON API

## What I Built

This project was built to practice building a complete React application from scratch, including reusable components, state management, API fetching, routing, and persistent client-side data.

## Run Locally

```bash
npm install
npm run dev
```
